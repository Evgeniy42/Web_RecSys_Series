# Веб приложение. Рекомендательный сервис для подбора сериалов

### Описание
Маленький проект, в котором основной функционал, это подбор рекомендации по сериалам.
Пользователь заходит на сайт, регистрируется. Находит сериалы, которые он смотрел и ставит им оценку 0-10.
С помощью этих данных производится рекомендаций: коллабративный подход по похожим пользователям.

### Стек
БД: PostgreeSQL
Бэкенд: Python (FastAPI)
Фронтенд: html шаблоны (jinja)

### Основной функционал
* Вход\Регистрация
* Оценка сериала (1-10)
* Поиск сериалов
* Рекомендация (Модель будет реализована в отдельном проекте. Пока заглушка.)

### Страницы
* Вход\Регистрация
* Профиль пользователя (Никнейм, список оценненых сериалов)
* Список сериалов на сайте.
* Поиск с фильтрацией.
* Результат рекомендации
